# Old analysis scripts

Archived root-level scripts:

- `analyse_fam.py` — compares AF and RF family results.
- `analyse_msa.sh` — generates a gapped alignment for one algorithm.
- `evaluate_all.sh` — runs the evaluation batches and renames their outputs.
- `evaluate_secondary_structure_data.py` — evaluates predicted RNA secondary structures.
- `get_all_gapped_alignments.sh` — generates gapped alignments for all configured algorithms.
- `get_gapped_alignment.py` — extracts aligned sequences from prediction data.
- `get_secondary_structure_prediction.py` — predicts secondary structure for an RNA sequence.
- `plot_3d_structures.py` — renders predicted and reference 3D structures.
- `plot_all_3d.sh` — runs the 3D plotting examples.
- `plot_final_secondary_structure_results.py` — plots final secondary-structure distributions.
- `plot_results.py` — plots grouped evaluation results and statistics.
- `plot_rna_monomer_sec_vs_3d.py` — compares monomer secondary-structure and 3D results.
- `plot_secondary_structures.py` — plots secondary structures from prediction data.
- `prepare_evaluation_data.py` — prepares evaluation inputs from prediction and reference data.
- `rna_msa_generator_base_pair.py` — generates MSA sequences constrained by base pairs.
- `run_evaluation.sh` — runs secondary-structure evaluation for supplied prediction directories.
- `summarize_secondary_structure_results.py` — summarizes secondary-structure evaluation results.
